# Informatics_10_2026

Данная программа провеяет баланс скобок в исходной строке

## Установка
```bash
git clone https://github.com/K0tB0ris/Informatics_10_2026.git
cd Informatics_10_2026
```

## Запуск программы
В консоль вводится строка из скобок. Скобки идут без пробелов. Строка заканчивает на '\n'.


## Результат работы
Если балан соблюдён в консоль выведется ответ "BALANCED", если нет, то "NOT BALANCED"

## Пример работы
```bash
cd src
gcc main.c -o main
./main
```
